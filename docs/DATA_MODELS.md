# Freight Desk data models

These are the initial domain models. They describe business data, not database
tables or API payloads. IDs are generated by the server and all timestamps are
stored as UTC ISO 8601 values.

## Common conventions

| Convention | Rule | Fictional example |
| --- | --- | --- |
| ID | UUID generated by Freight Desk | `2f7d5f0e-1b0f-4c6f-8d2c-4a1b1f2d3e40` |
| Timestamp | UTC, with an explicit offset | `2026-11-10T12:30:00Z` |
| Money | Integer minor units plus ISO 4217 code | `{ "amountMinor": 125000, "currency": "DKK" }` |
| Percentage | Integer basis points, where 10,000 is 100% | `9500` means 95% |
| Version | Positive integer, never reused | `3` |
| Source file | Retained original plus approved template reference | `carrier-rates-v2.xlsx` |

No model stores a password or browser token. Raw customer files stay in the
controlled document store; normalized values reference the source row where
possible.

## Enumerations

```text
Role: carrier | consultant | master
TenderStatus: draft | open | closed | awarded | archived
OfferState: draft | submitted | superseded | withdrawn
PricingUnit: kg | pallets | CBM | LDM | packages
RateBasis: per_shipment | per_kg | per_100kg | per_pallet | per_cbm | per_ldm | per_package
VatTreatment: included | excluded | zero_rated | reverse_charge | not_applicable
TemplateKind: shipment | carrier_rate | award
```

## Tender

The consultancy-owned request for carrier prices.

| Field | Type | Rule |
| --- | --- | --- |
| `id` | UUID | Server generated |
| `name` | Text | Human-readable tender name |
| `customerReference` | Text | Consultancy reference, not a secret |
| `status` | TenderStatus | Follows the lifecycle in BUSINESS_RULES.md |
| `ownerUserId` | UUID | Consultant or master |
| `deadlineUtc` | Timestamp | Required when open |
| `customerTimeZone` | IANA time-zone text | Used only for display |
| `currency` | ISO currency code | Tender comparison currency |
| `vatTreatment` | VatTreatment | Stored with the tender |
| `vatRateBasisPoints` | Integer | 0 to 10,000 |
| `zonePolicy` | Zone policy | Reject overlap or approved priority policy |
| `evaluation` | Evaluation policy | Cheapest or configured weighted score |
| `shipmentTemplate` | Template reference | Exact input template version |
| `carrierRateTemplate` | Template reference | Exact offer template version |
| `createdAtUtc`, `updatedAtUtc` | Timestamp | Audit and concurrency |
| `openedAtUtc`, `closedAtUtc`, `awardedAtUtc`, `archivedAtUtc` | Timestamp or null | Must match lifecycle state |

Fictional example: `Northern Denmark 2027` is open until
`2027-01-15T22:00:00Z`, displayed as 23:00 in `Europe/Copenhagen`.

The transport company that receives invitations and submits offers.

| Field | Type | Rule |
| --- | --- | --- |
| `id` | UUID | Server generated |
| `legalName` | Text | Legal company name |
| `displayName` | Text | Name shown to consultants |
| `countryCode` | Two-letter country code | Required |
| `externalReference` | Text | Optional consultancy reference |
| `status` | `active \| suspended \| archived` | Suspended companies cannot submit |
| `createdAtUtc`, `updatedAtUtc` | Timestamp | Audit and support |

## UserMembership

An authorization snapshot connecting an identity to a role and, for carriers,
to one company. Entra remains the identity source.

| Field | Type | Rule |
| --- | --- | --- |
| `id` | UUID | Server generated |
| `entraUserId` | Text | External identity identifier |
| `role` | Role | Exactly one product role in the initial model |
| `carrierCompanyId` | UUID or null | Required for `carrier`, null for consultancy roles |
| `status` | `active \| suspended` | Suspended membership is denied |
| `createdAtUtc`, `updatedAtUtc` | Timestamp | Changes are audited |

## Invitation

The link between an open tender and a carrier company.

| Field | Type | Rule |
| --- | --- | --- |
| `id`, `tenderId`, `carrierCompanyId`, `invitedByUserId` | UUID | All are required |
| `state` | `invited \| accepted \| declined \| expired \| revoked` | State is audited |
| `invitedAtUtc` | Timestamp | Required |
| `respondedAtUtc` | Timestamp or null | Required after response |

## Shipment

A normalized shipment row imported into a tender.

| Field | Type | Rule |
| --- | --- | --- |
| `id`, `tenderId` | UUID | Required |
| `sequence` | Positive integer | Stable row order |
| `originPostcode`, `destinationPostcode` | Text | Validated before pricing |
| `originCountry`, `destinationCountry` | Two-letter country code | Required |
| `quantities` | Quantity list | One or more of kg, pallets, CBM, LDM or packages |
| `originZoneId`, `destinationZoneId` | UUID or null | Null means unmatched |
| `sourceRowNumber` | Positive integer | Points to the source workbook |
| `dataVersion` | Positive integer | Changes create a new shipment version |

## PostcodeZone and PostcodeRange

A tender-specific zone map. A zone has one or more inclusive ranges.

```text
PostcodeRange {
  fromPrefix: two digits,
  toPrefix: two digits,
  priority: non-negative integer
}

PostcodeZone {
  id: UUID,
  tenderId: UUID,
  code: text,
  name: text,
  ranges: PostcodeRange[],
  dataVersion: positive integer
}
```

Ranges with `fromPrefix > toPrefix` are invalid. Overlaps are invalid unless
the tender has an approved priority policy. Gaps are valid data but produce an
unmatched shipment warning.

## RateBand

A carrier price for a zone and quantity band, stored inside a bid version.

| Field | Type | Rule |
| --- | --- | --- |
| `id`, `zoneId` | UUID | Required |
| `unit` | PricingUnit | Measurement used by the band |
| `basis` | RateBasis | How the amount is charged |
| `fromQuantity` | Non-negative number | Inclusive lower boundary |
| `toQuantity` | Number or null | Inclusive upper boundary; null means no upper limit |
| `price` | Money | Zero is explicit, never missing |
| `deliveryTime` | Delivery time | Minimum and maximum business days |
| `dataVersion` | Positive integer | Matches the bid version |

## Surcharge and service coverage

```text
Surcharge {
  id: UUID,
  name: text,
  kind: fuel | additional,
  calculation: percentage basis points or fixed Money,
  appliesTo: shipment | quantity | rate_band,
  vatTreatment: VatTreatment
}

ServiceCoverage {
  countryCodes: two-letter country codes[],
  zoneIds: UUID[],
  notes: text
}

DeliveryTime {
  minimumBusinessDays: non-negative integer,
  maximumBusinessDays: non-negative integer
}
```

## BidVersion

One immutable submitted offer version or one editable draft.

| Field | Type | Rule |
| --- | --- | --- |
| `id`, `tenderId`, `carrierCompanyId`, `createdByUserId` | UUID | Required |
| `versionNumber` | Positive integer | Increases per carrier and tender |
| `state` | OfferState | See offer lifecycle |
| `rates` | RateBand[] | Stored with this version |
| `surcharges` | Surcharge[] | Stored with this version |
| `serviceCoverage` | ServiceCoverage | Required |
| `createdAtUtc` | Timestamp | Required |
| `submittedAtUtc` | Timestamp or null | Required for submitted states |
| `supersedesVersionId` | UUID or null | Set when a new version replaces one |
| `withdrawnAtUtc` | Timestamp or null | Required for withdrawn state |
| `sourceTemplate` | Template reference or null | Original carrier file when used |

After submission, every field and source file in the version is immutable.

| Field | Type | Rule |

| `decision` | `confirmed \| cancelled` | A cancelled award remains in history |

## ExcelTemplate

An approved version of one of the three Excel contracts.

| Field | Type | Rule |
| --- | --- | --- |
| `id` | UUID | Server generated |
| `kind` | TemplateKind | Shipment, carrier rate or award |
| `version` | Semantic version | Never changed in place |
| `fileName` | Text | Approved file name |
| `checksumSha256` | Hex text | Detects accidental replacement |
| `status` | `active \| retired` | Retired templates remain readable |
| `approvedAtUtc` | Timestamp | Records customer approval |

## Permissions and lifecycle summary

- Consultancy users own tenders, shipments, invitations and awards.
- Carrier users own only their company's offer drafts and offer versions.
- Submitted bid versions are sealed until the deadline or a logged master
  unseal.
- A carrier can edit only its current draft while its invitation is active and
  the tender is open.
- A consultant can compare only closed or explicitly unsealed offers.
- A master can manage companies, memberships, archive records and audit access,
  but cannot remove immutable history.
